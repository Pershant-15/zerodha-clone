# Zerodha Clone (React)

A frontend clone of Zerodha's website, built with React.js. It recreates the clean, responsive design of India's largest stockbroker's landing site.

## Pages
- Home: Hero, Awards (Trust with confidence), Stats, Pricing, Education, Open Account  (built)
- About, Pricing, Products, Signup  (next passes)

## Highlights
- Reusable components (shared Hero and OpenAccount)
- React Router navigation
- Responsive layout (mobile, tablet, desktop)
- Flat solid colors only, no gradients
- Original hand-drawn SVG artwork

## Tech
React.js, Vite, React Router, HTML, CSS, Bootstrap

## Run
npm install
npm run dev

Built for learning purposes. Not affiliated with Zerodha.
